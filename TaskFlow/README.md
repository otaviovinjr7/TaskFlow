# TaskFlow — Gerenciador Inteligente de Tarefas

Aplicação web para organização de tarefas, desenvolvida com HTML5, CSS3 e JavaScript puro, utilizando LocalStorage para persistência de dados no navegador.

## Sobre o projeto

O TaskFlow foi desenvolvido como projeto de portfólio para praticar fundamentos do desenvolvimento front-end, manipulação do DOM, eventos, arrays, objetos e armazenamento local.

A aplicação permite organizar atividades por prioridade, acompanhar prazos e visualizar indicadores de produtividade em uma interface responsiva.

## Funcionalidades

- Cadastro de tarefas com título, descrição, prioridade e prazo.
- Edição e exclusão de tarefas.
- Marcação de atividades como concluídas.
- Identificação de tarefas atrasadas.
- Filtros por status e prioridade.
- Pesquisa por título ou descrição.
- Ordenação por prazo, prioridade ou data de criação.
- Indicadores de tarefas totais, pendentes e concluídas.
- Cálculo automático da taxa de conclusão.
- Persistência de dados com LocalStorage.
- Interface adaptável a computadores e dispositivos móveis.

## Tecnologias utilizadas

- Git e GitHub

## Como executar

1. Clone este repositório ou baixe os arquivos.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Cadastre suas tarefas e explore as funcionalidades.

Não é necessário instalar dependências, configurar um servidor ou utilizar um banco de dados.

## Limitações conhecidas

Os dados são armazenados localmente no navegador. Por isso, não existe sincronização entre dispositivos, autenticação de usuários ou armazenamento em servidor.
